# Glow Candle Website

Glow Candle is a responsive e-commerce website for showcasing and browsing scented candles. The website features a modern design and provides an easy shopping experience.

## Features

- Responsive Design
- Product Catalog
- Image Gallery
- About Section
- Contact Page
- Interactive User Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/maryammoamed43-cell/Glow-Candle-Website.git
```

2. Open the project folder.

3. Open the main HTML file in your browser.

> For the best experience, use the **Live Server** extension in Visual Studio Code.
